# Common Stack | VCS | Documentation

## 1. Introduction

Version Control System (VCS) is a tool that helps developers track changes in code, collaborate with teams, and manage different versions of a project efficiently.

---

## 2. What is VCS?

A Version Control System records changes to files over time so that you can recall specific versions later.

It helps in:

* Tracking history of changes
* Managing multiple contributors
* Reverting to previous versions

---

## 3. Why VCS?

* Enables team collaboration
* Maintains code history
* Prevents data loss
* Supports branching and merging
* Helps in debugging and rollback

---

## 4. Types of VCS

### 1. Local VCS

* Stores versions locally on a system
* Example: RCS

### 2. Centralized VCS (CVCS)

* Single central server stores all versions
* Example: SVN

### 3. Distributed VCS (DVCS)

* Every developer has a full copy of repository
* Example: Git

---

## 5. Advantages of VCS

* Better collaboration
* Complete version history
* Easy rollback
* Branching support
* Backup and recovery

---

## 6. Disadvantages of VCS

* Learning curve for beginners
* Merge conflicts
* Requires proper management

---

## 7. VCS Workflow

1. Developer creates/updates code
2. Changes are added (staging)
3. Code is committed with message
4. Changes are pushed to repository
5. Other developers pull latest changes
6. Code review and merge happens

---

## 8. Common Commands (Git Example)

| Command    | Description           |
| ---------- | --------------------- |
| git init   | Initialize repository |
| git clone  | Copy repository       |
| git add    | Stage changes         |
| git commit | Save changes          |
| git push   | Upload changes        |
| git pull   | Fetch latest changes  |

---

## 9. Best Practices

* Write meaningful commit messages
* Use branching strategy (feature, dev, main)
* Commit small and frequent changes
* Pull latest changes before pushing
* Avoid committing sensitive data

---

## 10. Conclusion

VCS is a critical tool in software development that ensures efficient collaboration, version tracking, and safe code management.
