## 1. Introduction

Python is a high-level, general-purpose programming language known for its simplicity and readability.

It is widely used in:
- Web development  
- Automation  
- Data science  
- DevOps  

Goal: Easy to write, easy to read, and fast to develop.



## 2. History

| Year | Event |
|------|-------|
| 1991 | First release by Guido van Rossum |
| 2000 | Python 2 introduced major features |
| 2008 | Python 3 released (modern version) |
| 2020 | Python 2 officially ended |
| 2023+ | Performance improvements in Python 3.x |



## 3. Features

| Feature | Description |
|---------|------------|
| Simple Syntax | Easy to read and write |
| Interpreted | No compilation needed |
| Dynamic Typing | No need to define variable types |
| Large Library | Built-in modules available |
| Cross Platform | Runs on Linux, Windows, macOS |

## 5. Conclusion

Python is simple, powerful, and widely used across industries.

It is one of the best languages for beginners and professionals.
