## 1. Introduction

Make is a simple tool used to automate repetitive development tasks.



## 2. What is Make?

Make is a **build automation tool** that runs commands defined in a `Makefile`.

| Attribute | Detail |
|-----------|--------|
| Type | Build Tool |
| File | Makefile |
| Use | Run tasks like build, test, deploy |
| Command | make <target> |


## 3. Why Make?

Developers often run long and repeated commands.

Make solves this:

| Problem | Solution |
|---------|----------|
| Long commands | Short targets (make build) |
| Repetition | Automates tasks |
| Inconsistency | Same command for everyone |
| Errors | Reduces manual mistakes |


## 4. Key Features

| Feature | Description |
|---------|------------|
| Targets | Named tasks |
| Dependencies | Run tasks in order |
| Variables | Reuse values |
| .PHONY | Always run tasks |
| Simplicity | Easy to use |


## 5. Conclusion

Make simplifies task execution and improves consistency across teams.
